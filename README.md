# اعلانات ضروری

اپلیکیشن وب چندزبانه با Express و MySQL. اعلان‌های عمومی فقط پس از تأیید مدیر نمایش داده می‌شوند؛ نام و شماره تماس با AES-256-GCM رمزگذاری شده و فقط در پنل مدیریت رمزگشایی می‌شود.

## نمونه‌های آزمایشی

در اولین راه‌اندازی نسخهٔ به‌روزشده، برنامه به‌صورت خودکار ۲۰ مورد آزمایشیِ غیرواقعی برای هر دستهٔ اعلان خون، گم‌شده و پیدا‌شده و ۲۰ مورد برای فهرست اهداکنندگان می‌سازد. همه با وضعیت «در انتظار بررسی» ذخیره می‌شوند و عنوان، منطقه و توضیحات آن‌ها آشکارا آزمایشی است. در پنل مدیر، دکمهٔ «تأیید و نمایش نمونه‌های آزمایشی» این ۸۰ مورد را منتشر می‌کند؛ نمونه‌ها در آمار واقعی کمک‌ها شمرده نمی‌شوند. هر نمونه را می‌توان از فهرست پنل مدیریت حذف کرد.

## پیش‌نیازها

- Node.js 20 یا بالاتر
- MySQL 8 یا MariaDB سازگار
- برنامهٔ احراز هویت سازگار با TOTP برای ورود مدیر
- کلید Google Maps JavaScript API برای نقشه (اختیاری تا زمان راه‌اندازی)

## راه‌اندازی محلی

1. پایگاه داده را ایجاد کنید: `mysql -u root -p < schema.sql`
2. فایل `.env.example` را به `.env` کپی و تنظیمات دیتابیس را وارد کنید.
3. یک کلید ۳۲ بایتی تصادفی برای `PII_ENCRYPTION_KEY` بسازید و آن را به ۶۴ رقم هگز تبدیل کنید. برای `ADMIN_TOTP_SECRET` یک کلید تصادفی Base32 با دست‌کم ۳۲ نویسه از حروف `A-Z` و ارقام `2-7` بسازید. کلید دوم را در برنامهٔ احراز هویت به‌عنوان حساب Time-based (TOTP) ثبت کنید و هر دو کلید را محرمانه نگه دارید.
4. `npm install` سپس `npm start` را اجرا کنید.
5. سایت: `http://localhost:3000` و پنل: `http://localhost:3000/admin`

برای ورود، شمارهٔ مدیر را با قالب E.164 در `ADMIN_PHONE` تنظیم کنید؛ چند مدیر را با ویرگول جدا کنید. شمارهٔ مدیر و کد شش‌رقمی فعلی برنامهٔ TOTP در فرم ورود وارد می‌شوند. در Render، کلید TOTP را فقط از بخش Environment Variables تنظیم کنید؛ آن را در Git یا `.env.example` قرار ندهید. برای Maps، `GOOGLE_MAPS_API_KEY` را تنظیم و کلید مرورگر را به دامنه‌های سایت و Maps JavaScript API محدود کنید. این کلید ذاتاً در مرورگر استفاده می‌شود؛ آن را در سمت سرور به‌عنوان راز نگه ندارید.

## API

- `GET /api/announcements`: فقط اعلان‌های تأییدشده
- `POST /api/announcements`: ثبت اعلان با وضعیت pending
- `POST /api/auth/login`: ورود مدیر با شمارهٔ مجاز و کد TOTP
- `GET /api/admin/announcements`: اعلان‌ها و اطلاعات تماس رمزگشایی‌شده، مدیر-مجاز
- `PATCH /api/admin/announcements/:id`: تغییر وضعیت
- `DELETE /api/admin/announcements/:id`: حذف اعلان

## پیش از انتشار عمومی

از TLS استفاده کنید، کلیدهای API را محدود کنید، برای MySQL کاربر جدا با کمترین دسترسی بسازید، پشتیبان رمزگذاری‌شده بگیرید و دسترسی مدیر را از شماره‌های مورد اعتماد محدود کنید. نرخ‌محدودسازی پیش‌فرض Express در حافظه است؛ برای چند نمونهٔ سرور، آن را به Redis منتقل کنید. مسیر تماس کاربران، گزارش تخلف، احراز هویت کاربران عادی و گردش‌کار تأیید هویت محلی نیازمند سیاست عملیاتی شما هستند.
